claude-status — display firmware

Flash an ESP32-S3 to render your Claude Code state on a HUB75 LED panel.

This is the display firmware piece of claude-status. For the full system overview — what claude-status is, how the plugin / bridge / display fit together, and the install walkthrough that gets the host side talking to your hardware — head to the plugin repo.

If you're already past that and just need to put firmware on a board: plug a supported ESP32-S3 into your computer with USB-C, pick your board below, and click Flash.

Supported boards

SparkFun Thing Plus ESP32-S3

The original development board for this project. Compact, Qwiic connector, microSD slot. HUB75 pins are split across both headers.

Lonely Binary ESP32-S3 N16R8 Gold Edition

16 MB Flash, 8 MB octal PSRAM. All HUB75 pins live on the left header, GPIO 4–16 contiguous — a clean ribbon layout.

Browser support

Web flashing uses WebSerial, which is supported in Chrome, Edge, and other Chromium-based browsers. Firefox and Safari don't support WebSerial; for those browsers, use esptool directly with the .tar.gz archives attached to each release.
